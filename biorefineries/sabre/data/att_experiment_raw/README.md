# ATT raw experimental data

Verbatim cell values of the collaborators' workbook
`ATT Inputs and Assumptions_261005.xlsx` (UCLA ATT experiments), one CSV per
sheet:

| File | Sheet | Content |
|---|---|---|
| `experimental_results.csv` | Experimental results | Gas yields (H2, CH4, CO, Gas 4, CO2; mmol/g daf), charge masses and conditions for ATT, CatATT, Ni-ATT and Ni-CatATT |
| `energy_analysis_assumptions.csv` | Assumptions for energy analysis | Collaborators' feedstock/process assumptions, emission factors and boundary text |

Each row is `cell, type, value`: every non-empty cell, with its original
Excel type (`int`, `float`, `str`) and the full-precision value (floats are
written with Python `repr`, so they read back bit-identical). Nothing was
rounded, recalculated or edited.

Source workbook SHA-256:
`879812409893953d1692507437197ba8f62c0e218bdf37fe979df051e19b9c9c`

Not copied from the workbook: the embedded flowsheet image, a reviewer cell
comment and the document properties (author names). They are not data used by
the model. The workbook itself is not distributed with the code.

## How the data are used

| Role | Where | Notes |
|---|---|---|
| Raw experimental data | this folder | Reference copy of the measurements; never edited |
| Experimental dataset (cell-referenced transcription) | `../att_experiment.yaml` | Read by `analyses/att/experiment.py` (sheets A1-A4, lab screening LCA B1) |
| Model input (U2 baseline yields) | `../att.yaml`, `att.reactor.cases.Ni-CatATT` | Read by the process model (`units/_att.py`) |
| Model assumptions | `../att.yaml`, `../att_tea.yaml`, `../att_lca.yaml`, `../feedstock.yaml`, `../tea.yaml`, `../preprocessing.yaml` | Engineering, TEA and LCA assumptions of the plant model |
| Calculated results | not stored in the package | Regenerated by `test/run_att_*.py` |

`analyses/att/experiment.py:verify_att_experiment_workbook` checks the YAML
transcription and the four U2 yields plus the ignored Gas 4 value in
`att.yaml` against these files by exact equality (results sheet A4 and
`test/test_att_final.py`), so the copies cannot drift apart. To also check
these files against the original workbook, set `ATT_SOURCE_WORKBOOK` to its
path and run `test_att_final.py`.
